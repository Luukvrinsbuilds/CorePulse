# CorePulse 🖥️

**A lightweight PC monitoring dashboard built with Python.**

CorePulse is a personal software project that monitors computer performance in real time. It displays CPU usage, RAM usage and disk usage in a clean, dark-themed dashboard.

I'm building CorePulse as a project for Hack Club Terra to improve my Python programming skills and learn more about system monitoring and desktop application development.

## ✨ Features

- **CPU monitoring** — View current processor usage.
- **RAM monitoring** — Monitor memory usage and used RAM.
- **Disk monitoring** — See disk usage and available storage space.
- **Live updates** — System statistics refresh automatically.
- **Dark interface** — A modern dashboard built with CustomTkinter.

## 🛠️ Built With

- Python 3.11.9
- CustomTkinter — desktop user interface
- psutil — system performance information
- Matplotlib — planned and future graph visualizations

## 🚀 Getting Started

### Requirements

- Windows
- Python 3.11.9
- pip

### Installation

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment:

   ```bash
   py -3.11 -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

4. Install the dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Start CorePulse:

   ```bash
   python main.py
   ```
